Connect the editor to GitHub

This page saves your edits straight to your site, so it needs a key from your GitHub account. You only do this once per browser.

  1. Open GitHub’s new token page.
  2. Name it “Portfolio editor” and pick an expiration date.
  3. Under Repository access, choose Only select repositories and pick Max_Lasek_Portfolio.
  4. Under Permissions, find Contents and set it to Read and write.
  5. Click Generate token, copy it, and paste it below.

The key is stored only in this browser. Click “Sign out” in the editor to remove it.
