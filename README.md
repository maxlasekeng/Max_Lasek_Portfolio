# Max Lasek — Portfolio

Static site. No build step: edit the HTML files directly.

- `index.html` — home page
- `projects/` — one page per project
- `css/style.css` — all styling (colors are at the top)
- `images/` — photos and renders
- `resume/` — résumé PDF linked from the header

To add a project: copy a file in `projects/`, change the text and images,
then copy one `<article class="project">` block in `index.html` and point it at the new page.
